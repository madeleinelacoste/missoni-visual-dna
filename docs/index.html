What it measures

Similarity of the garment's CLIP embedding to Missoni's runway looks, calibrated so that 50 = a typical Missoni look. In tests it responds mostly to knit pattern (zigzags, stripes), so a chevron knit by another maker can score high.

What it isn't

Not an authentication tool. It knows 135 looks from nine collections; it can't tell a genuine piece from a copy, and it's harsher on prints.

The research

Six chapters on Missoni's color, pattern and eras, with method and limitations, on GitHub.

Models: SegFormer-B2 clothes (NVIDIA SegFormer licence, non-commercial) and CLIP ViT-B/32 (OpenAI, MIT), quantized ONNX versions by Xenova, run with transformers.js.
